# Games consolidation and production cutover

## Decision and scope

Appmonto Studio is the public studio/publisher for Happy Octo Puzzle, Clever Beaver
and Closer Look: Farm. “Games” is a section, not a brand. KidLogic Loft is retired
as a public-facing brand. Closer Look is the interactive diorama series; its first
release is Closer Look: Farm (formerly Cozy Meadow Farm). The series can span
unrelated settings; no other releases are announced. Elia keeps its identity and
https://getelia.app destination. Its repository is outside this migration.

Advertising is prohibited across the studio. Optional in-app purchases are allowed.
Closer Look: Farm purchases are planned; no price, country, currency, subscription,
parental gate or included-content offer has been inferred. Happy Octo's current
free/no-subscription description is retained from the source as an individual app
statement. Core offline play is distinguished from downloads, billing, restoration
and support. Published package ID `com.kidlogicloft.happyocto` and its Play URL are
unchanged. Legal operator and the encoded imprint payload are unchanged.

## Hosting design and constraints

GitHub Pages cannot provide this site's arbitrary server-side redirect map.
The destination therefore stays on GitHub Pages while the old custom domain uses
a small Cloudflare Worker maintained **in this Appmonto repository**. It has no
origin fetch, database or dependency on the old Pages project/repository.
`infra/redirects/wrangler.jsonc` declares both custom domains; `worker.mjs` imports
the explicit allowlisted route map and returns HTTP 301.

Prerequisites: a Cloudflare account with an active zone for `kidlogicloft.com`,
registrar control, and permissions to deploy a Worker and connect its custom
domains. Existing DNS/provider account state has not been inspected. This is a
prepared option, not a claim that Cloudflare is already configured. Follow
[Cloudflare Custom Domains](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/).
A custom domain needs its own zone; conflicting CNAME records must be removed
before attachment. Do not remove mail-related records. Cloudflare manages the
Worker's DNS target and certificates; do not guess a workers.dev CNAME.

The provider-owned project URL
`https://appmonto-studio.github.io/kidlogicloft.github.io/` cannot be assigned to
this Worker. Nine `kidlogicloft.github.io/.../index.html` compatibility files in the
destination preserve page/locale targets if GitHub routes the former project path
through the account site after the project Pages site is disabled. These are
`noindex` HTML refresh + canonical + visible links, **not HTTP 301**. Verify this
provider behaviour during cutover before repository deletion. If it does not
route to these files, keep the old project/repository temporarily and resolve
that alias separately. Never assume its redirect survives deletion. Strict
server-side 301 continuity on GitHub-owned URLs requires GitHub support or keeping
the old Pages service; the custom-domain 301s do not have that dependency.

## Rollback

Before deletion, retain both repositories, the source bundle, prior DNS records,
Pages settings and domain verification. If only the new site needs repair, keep
legacy redirects online and restore/fix the destination pages first so app policy
links do not disappear. To revert the full cutover, re-enable old project Pages
with `kidlogicloft.com`, restore its old DNS records (removing Worker custom-domain
bindings first), and verify TLS plus all old privacy routes. Then revert the
migration commit(s) on Appmonto with a new revert commit, build and publish normally;
do not rewrite history. Retain working support forwarding during rollback and
restore store URLs only after their destinations work. Permanent 301s may be cached:
keep new destination routes serving useful content until caches and installed-app
references have been addressed; DNS rollback alone cannot undo cached redirects.
